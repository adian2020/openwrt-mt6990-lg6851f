# 系统定时重启插件

用户明确要求添加到系统菜单并启动云编译，自动监控关闭。只合入本插件，软件源扩充及开机排查继续暂停；两组未完成改动留在原工作目录，没有纳入本次构建。

界面、菜单、权限和简体中文翻译以ImmortalWrt LuCI的319f7c96e3530246cf91cfdd9bacb3fa44dc3a4e为固定来源，保留Apache-2.0版权说明；软件包位于package/vendor/luci-app-autoreboot。

- 菜单为“系统 → 定时重启”，默认计划关闭。按设备系统时区配置，可添加多条计划。
- 保存并应用通过UCI触发服务重载。服务端再次检查分钟、小时、日、月和星期字段，不将未经检查的UCI文本写成cron命令。
- 通过crontab管理带autoreboot标记的行，不清空其他任务。重载不先停用旧计划；无效新配置保留旧计划。停止服务只删除本插件任务。
- 临时文件权限0600、互斥更新、退出清理；不写入banner，不额外添加常驻采集进程。
- 固件配置预装luci-app-autoreboot、对应中文包和flock；编译前确认选择，完成后核对实际rootfs文件，保持原有A/B签名流程。

验证只执行临时crontab计划生成，不执行/sbin/reboot：覆盖默认关闭、系统菜单路径、启用保留其他任务、多计划重载、非法范围/换行/命令文本拒绝，以及停用清理。云编译运行状态和固件实际定时重启仍需分别验收，不把本地检查当作实机验证。

本地五项计划测试、六项WiFi启动回归、三项软件源回归及包完整性检查通过；真实LuCI包元数据解析得到插件、中文包及flock依赖。本地完整make defconfig因环境缺少ncurses开发文件和rsync、默认umask不符而未完成，没有使用FORCE跳过；正常云工作流安装这些依赖，并强制检查defconfig后插件及中文包为预装状态。
