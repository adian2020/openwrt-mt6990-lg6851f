# 刷新看板时保留数字速率

用户要求刷新页面后显示数字，允许先显示上一次采样结果。撤销“采样中”作为
正常等待占位的方案，使用同标签页 sessionStorage 保存真实的两次计数结果及
末次样本。页面初始化先读取当前接口计数，校验缓存的启动标识、接口、采样时间
和计数未回退，仅复用10秒内的有效速率；界面注明“最近一次速率”。复用时不
延长旧样本有效期，后续仍按2秒采样周期更新。

首次访问、缓存失效或浏览器禁用存储时，在页面初始化中间隔250毫秒读取两次
真实计数，计算初始数字，然后开始2秒周期。没有有效接口计数时保留未获取，
不把等待或读取失败虚构为零速率。短时间窗口的数值可能比2秒窗口更波动。
缓存只在浏览器标签页中保存，不写路由器持久存储，不增加后台周期采集器。

手机390px、桌面1280px浏览器验证覆盖首次显示数字、重进看板复用最近速率、
拒绝旧启动/不同接口/过期/计数回退/损坏缓存及浏览器存储不可用。正常加载后
继续原有周期更新；不改变后台RPC采集、射频、LED、短信或软件源。
