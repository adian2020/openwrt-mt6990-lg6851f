# v1.0.11 实机网页超时修复

实机确认：system board、get_apn 均立即返回，get_rates 约 0.12 秒，
get_dashboard 到 30.03 秒被 RPC 超时终止且没有输出；内存充足，未见 OOM 日志。
两条模组状态 shell 为父子进程，不是两个独立服务。

get_dashboard 原来在 RPC 调用内读取传感器、查询网络，再对每个无线接口同步
请求 rpcd 的 iwinfo 对象。接口多或请求阻塞时，整张看板无法返回，还会影响
其它页面共享的 RPC 服务。本轮修复这一同步请求结构，不通过放大30秒限额解决。

新路径：网页仅读取 /tmp/lg6851f-dashboard-v2.json，校验启动标识和采集年龄；
首次没有缓存时立即返回基础结构。后台工作由非阻塞锁保护，所有标准描述符
在启动时重定向，不让 RPC 的 popen 管道等待后台退出。采集系统、网络、无线和
完成阶段分别原子发布，单个命令限制2秒，命令批次限制18秒，进程外层限时25秒。

无线信息改用独立 iwinfo 命令，不再对 rpcd 的 iwinfo 对象发起嵌套请求。
固件配方和配置增加 iwinfo 命令；API不触碰AT/射频，不改拨号、LED或已有插件。
缓存失效时保留显示并标记状态，不用旧启动的缓存冒充当前状态。

scripts/lg6851f-dashboard-hotfix.sh 是仅针对当前81c83ea固件的可回退验证脚本，
先下载到私有目录、编译检查，再备份并替换四个网页后端文件，最后重启rpcd。
它不刷写固件，不运行升级迁移，不清理overlay，也不改变网络和射频设置。
当前固件没有iwinfo命令时，无线细节在这次临时验证中缺失；下一版固件已补依赖。
回退脚本恢复原RPC文件，新增未被原RPC引用的采集文件保留但不会启动。

验证：77项本地回归通过，包含读取新鲜缓存不启动子进程、拒绝旧启动缓存、
后台逐阶段发布、无线解析和不调用rpcd iwinfo；手机和桌面验证首次无缓存时
页面直接打开。此结论不代替路由器实机热修复后的验证。
