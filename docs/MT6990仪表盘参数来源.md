# MT6990 仪表盘：截图字段与真实数据来源

编译已暂停。本文件是来源核对结果，不是实机测量报告。
“已有来源”表示可通过当前驱动/系统接口取得；“接口线索”仅表示二进制中
存在符号或输出字段，调用结构、单位和本机返回值仍须验证。

## 已有来源：先取得本机原始值

| 截图字段 | 本机来源 | 转换与限制 |
|---|---|---|
| 型号、系统版本 | ubus system.board | 读取当前设备，不使用截图的固件编号 |
| 系统运行时间 | /proc/uptime 或 ubus system.info | 秒转换为天/小时 |
| 运营商、SIM、注册状态 | /tmp/lg6851f-modem-status.state；luci.modem5g.get_status | 保留缓存时间，超过有效期不显示为实时 |
| 当前 LTE/NR、RSRP/RSRQ/SINR | 状态缓存；原有 AT+ECELL、AT+CESQ 读取路径 | NR ECELL 原始值按现有代码转换；255 是无效值，不是 0；不能以 LTE 公式转换 NR |
| PCI、ARFCN、服务/邻小区 | 原有 get_cells / AT+ECELL | 同一响应生成信号和小区信息，避免把不同时间的样本拼在一起 |
| 当前频段 | ECELL + 厂商 band_info/CA 信息 | ARFCN 范围重叠（例如 n77/n78）时不能只靠频点猜唯一频段 |
| APN | UCI network.modem5g.apn | 不读取 APN 密码 |
| IPv4/IPv6、DNS、网关、接口在线状态 | ubus network.interface.modem5g status | 按实际 l3_device 读取，不写死 ccmni3 |
| 蜂窝连接时长 | 上述 status 的 uptime | 不是设备开机时间 |
| 下载/上传速率 | 实际 l3_device 的 sysfs statistics/rx_bytes、tx_bytes 两次采样 | 字节差 / 实际时间差；Mbit/s 要乘 8；接口重建需重置基线 |
| 累计收发 | 上述 rx_bytes、tx_bytes | 是接口本轮生命周期统计，不冒充跨重启、月度或运营商计费总量 |
| CPU 利用率 | /proc/stat 两次采样 | 不能用 load average 代替百分比；不要重复计算 guest 时间 |
| 内存 | /proc/meminfo 的 MemTotal、MemAvailable | 单位 kB；已用 = 总量 - 可用 |
| 存储 | df /overlay | 当前实机为 P46 ext4；不能用只读 SquashFS 的占用代替 |
| CPU 当前/最高频率 | /sys/devices/system/cpu/cpufreq/policy*/scaling_cur_freq、cpuinfo_max_freq | kHz 转 MHz；scaling_max_freq 是策略上限，应与硬件最高频率区分 |
| CPU 温度 | thermal_zone*/type、temp；现有 luci.pwmfan 温度读取 | 按 cpu_little* 等实际传感器名匹配，毫摄氏度转摄氏度 |
| Wi-Fi 温度 | hwmon*/name、temp*_input、temp*_label | 必须先确认传感器属于 mt76/MT7996，不能把 SoC 温度改名 |
| SSID、信道、国家码、隐藏 SSID、加密 | UCI 白名单 + iw/iwinfo 的运行状态 | 配置值与当前运行值分别显示；不输出无线密码 |
| 无线客户端、信号、协商速率 | iw station dump 或 iwinfo assoclist | 协商速率不等于实时传输速度；区分 2.4GHz/5GHz Wi-Fi 与蜂窝 5G |
| DHCP 租约、客户端地址 | /tmp/dhcp.leases 或 DHCP ubus 接口 | 关联客户端和 DHCP 租约是两类列表 |
| LAN 地址 | ubus network.interface.lan status | 不写死 192.168.1.1 |
| IMEI、IMSI、ICCID | 既有状态采集器 | 显示默认脱敏；不能把零值当作真实号码 |
| 会话总数及上限 | /proc/sys/net/netfilter/nf_conntrack_count、nf_conntrack_max | Linux 连接跟踪，不是硬件 PPE 绑定条目数 |

## 已在当前厂商二进制找到的高级接口

证据取自仓库自带的 sample_nw、libqlril.so、libqlnet.so 的符号和格式字符串。
尚未在用户路由器执行新增命令。交互菜单编号仅用于审计，不能据此拼接未经
验证的输入流；错误的输入对齐可能进入设置菜单。

| 截图字段 | 已找到的接口/原始字段 | 还需确认 |
|---|---|---|
| 载波聚合 | ql_nw_get_ca_info；sample_nw 的 25 项（GET ALL INFO 子项） | 当前 RRC 状态下是否有有效载波；不能把空闲态无结果当作不支持 |
| 每载波制式、频段、PCI、ARFCN | pcc_type/pcc_band/pcc_pci/pcc_arfcn；对应 scc_* | 载波数组数量、PCC/SCC 排列；不假设永远一条 NR |
| 上下行带宽 | pcc_dl_bandwidth/pcc_ul_bandwidth；scc_*；ql_nw_get_band_info 的 lte/nr_dl/ul_bandwidth | CA 的整数单位/枚举需要核对；band_info 的字符串与 CA 输出应交叉验证 |
| 上下行 MCS | pcc_dl_mcs/pcc_ul_mcs；scc_* | MCS=0 可以是合法值，不应按缺失处理 |
| 调制方式 | pcc_dl_modulation/pcc_ul_modulation；scc_* | 数字枚举到 QPSK/16QAM/64QAM/256QAM 的映射，不能猜 |

| 活动带宽部分 BWP | pcc_dl_bwp_bandwidth/pcc_ul_bwp_bandwidth；scc_* | 不等同于载波总带宽 |
| 网络 AMBR 上下行 | ql_nw_get_band_info；net_ambr_dl/net_ambr_ul | 字符串单位、上下行顺序、无效值；不是实测速率或套餐限速承诺 |
| IMS AMBR | ims_ambr_dl/ims_ambr_ul | 不能拿 IMS 的值替代默认数据承载 |
| EN-DC 可用/限制 | ql_nw_get_endc_status；endc_available、dcnr_restricted | 网络可用状态不是用户允许开关；此 getter 不提供已验证的 setter |
| 当前频段限制、模组支持频段 | ql_nw_get_band_mode；Current_setting_bands / Which_bands_md_system_supports | 原有锁频 wrapper 的 get 已包含两种读取；必须解码实际 mask，不能硬编码旧数组 |
| 频段能力遗漏 | sample_nw 明示 RG620T_EU LTE 包含 B46，原 UI 列表没有 B46 | NR 能力也应读取 mask；截图的 n75/n76 等不能未经返回验证就照抄 |
| 网络模式设置 | ql_get_pref_nwmode、ql_nw_get_nwmode、ql_nw_get_nr_disable_mode | 是首选/允许模式，不能直接当作当前 SA/NSA 连接状态 |
| 当前 SA/NSA | 数据注册状态、RAT 和 CSCON CORE NETWORK 的 EPC/5GCN 等是线索 | 需要核实当前 RAT 枚举与连接组合；“5G”不自动等于“5G SA” |
| QCI | libqlnet.so 导出 ql_data_call_get_qos_info | 还未核实返回结构是否包含所需 QCI、活动 call_id 的选择及单位。CQI 是信道质量指标，绝不是 QCI |
| 模组固件版本 | libqlril.so 导出 ql_dm_get_software_version；AT 只读身份路径 | 需要读回。/etc/quectel-project-version 可能只是厂商用户态版本，不能直接当作基带固件版本 |
| 基带温度 | 尚未确认独立传感器/厂商 getter | 保留未获取，不拿 CPU/Wi-Fi 温度代替 |

## PPE 硬件会话：已发现不适合直接轮询的旧接口

驱动源码位于 package/vendor/mt6990-hwnat/src/hw_nat/。

- hnat_dbg_proc.c 的 entry_read() 遍历 ppe_foe_base/ppe1_foe_base，并按
  dbg_entry_state 统计 PPE0/PPE1；结果主要通过 pr_notice 输出到内核日志。
- /proc/hnat/hnat_entry 不是可直接用 cat 得到短小 JSON 的统计接口。
  周期读取会遍历并打印条目，不应为页面刷新不断调用。
- 邻近 cpu_reason_read() 还会清空诊断计数。采集脚本不读取这些调试节点。
- foe_fdb.h 的 FOE_4TB_SIZ 由内核配置选择 1K/2K/4K/8K/16K/32K；上限
  不能无条件照抄截图的 32768。
- 正式接入应增加只读聚合接口，使用合适的一致性保护，仅返回两套表的
  当前 BIND 数及真实容量，不打印每条会话，不混用 nf_conntrack_count。

## 实机取值的下一步

先运行 scripts/lg6851f-collect-dashboard-data.sh。它只读系统、无线状态及
已有的蜂窝缓存，不打开新 AT/MIPC 通道，不改变射频或锁频，不停止服务。

将脚本通过 SFTP 放到路由器 /tmp，然后：

    sh /tmp/lg6851f-collect-dashboard-data.sh > /tmp/mt6990-dashboard-data.txt

取回该输出后可以确认实际传感器名、网络接口名、频率、温度、流量、无线
状态及哪些缓存字段已具备。脚本不会填入截图示例值。
高级厂商接口随后单独核实调用 ABI 与读回结果，沿用既有控制通道所有权、
互斥和关闭冷却时间。未确认字段先保持“未获取”，不启动编译掩盖缺口。
