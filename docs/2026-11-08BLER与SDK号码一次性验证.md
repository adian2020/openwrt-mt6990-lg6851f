# BLER与SDK号码一次性验证

用户在此前放弃BLER订阅后，重新明确要求尝试BLER和SDK本机号码获取。本次仅提供人工运行的诊断脚本，不安装常驻服务，不恢复默认BLER订阅，不恢复看板号码行，不启动编译或监控。

## 接口核对

- sample_nw包含NR/LTE上下行BLER打印格式；NR吞吐回调入口45，参数非零注册、0注销。测试只用NR入口，顺序0初始化、45/1注册、等待20秒、45/0注销、1释放、-1退出。不调用射频、频段或短信设置。
- 本仓库libqlril.so导出ql_sim_get_phone_num。AArch64反汇编0xe5c4至0xe8c8确认三个参数为槽标识、缓冲区、长度，槽标识校验允许0xB01/0xB02；读取请求0xB02、载荷为4字节槽标识，SDK接收并复制83字节号码缓冲区。
- libql_uinf.so的ql_ril_sync_request（0x37dc起）构建id、data_len、data，并调用ril对象的ril_request方法。本脚本只发送id=0xB02、槽标识0xB01的单项只读请求；不尝试第二槽，不调用SIM写入、PIN或APDU接口。
- ucode ubus STRING补末尾NUL，因此3字节01 0b 00加自动补的NUL形成SDK输入01 0b 00 00。只接受匹配请求ID、成功结果、声明83字节、实际82或83字节的响应。完整号码需符合数字或前导加号格式；空返回不编造号码，其他响应不猜测布局。

## 执行与收尾

脚本scripts/lg6851f-probe-bler-phone.sh仅接受phone/bler两个模式；检查板型、蜂窝up状态，使用BusyBox兼容的非阻塞flock有界等待，共享控制锁。SDK号码查询有硬超时；NR测试使用FIFO、45秒进程超时、正常注销及信号/异常退出后的补发注销。关闭后保留6秒通道冷却，不停止其他进程、不重启设备或网络。若补发注销失败，必须保留返回结果，不能声称已成功注销或反复重试。

这仍是未经实机验证的探针：返回值可能为空或不支持；BLER数字单位与比例需核对，不直接当百分比。手机号接口可能与CNUM一样受SIM存储内容限制，不保证能取得号码。

## 检查

隔离传输测试执行实际shell菜单流程，验证注册后注销/释放/退出及锁释放；原生固定版本ucode验证SDK请求字节、号码/空值、错误ID/错误结果/截断数据和服务缺失。模拟数据不作为实机成功证据。
